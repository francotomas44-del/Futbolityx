# Documentos legales de Futbolityx

Este directorio reúne el conjunto de documentos legales de **Futbolityx** (sitio
`https://francotomas44-del.github.io/Futbolityx/` y aplicación web instalable).

> **Aviso:** estos documentos fueron redactados para describir con precisión el
> funcionamiento real de Futbolityx. No constituyen asesoramiento legal. Antes de
> un uso comercial, de la creación de una sociedad o de la publicación en una
> jurisdicción distinta de la Argentina, conviene que un profesional revise el
> conjunto.

## Cómo se publican

- Los documentos viven en este directorio como Markdown (fuente única).
- La página [`legal.html`](../../legal.html) los muestra dentro de la app, con
  índice y anclas, leyendo estos mismos archivos.

  enlazan a esa página.
